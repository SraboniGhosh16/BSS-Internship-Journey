# Phase 3 - Git & GitHub

## Overview

Phase 3 is part of my BSS Software Engineering Internship learning journey. This phase focuses on understanding Git and GitHub and practising version control workflows commonly used in software development.

The objective was to learn how to manage source code, track changes, work with branches, resolve merge conflicts and collaborate through GitHub repositories.


## Learning Objectives

### Git Topics

- Git installation and configuration.
- Initialising repositories using `git init`.
- Cloning repositories using `git clone`.
- Staging changes using `git add`.
- Creating commits using `git commit`.
- Uploading changes using `git push`.
- Working with branches.
- Merging branches.
- Identifying and resolving merge conflicts.

### GitHub Topics

- Creating and managing GitHub repositories.
- Working with branches and pull requests.
- Creating and managing issues.
- Writing README files and project documentation.
- Connecting local Git repositories with GitHub.
