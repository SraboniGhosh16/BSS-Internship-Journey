# Personal Portfolio Website

## Overview

This is my personal portfolio website, developed to showcase my skills, projects, learning journey and background in web development.

The website serves as a central place to present my work, demonstrate my frontend development skills and provide an easy way for visitors to connect with me.

## Live Demo

[**Visit My Portfolio**](https://srabonighoshportfolio.netlify.app)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Personal introduction and profile section.
- About me section.
- Skills and technical expertise showcase.
- Projects section highlighting completed work.
- Contact section for communication.
- Responsive layout for different screen sizes.
- Interactive user interface and navigation.

## Concepts Practised

- Semantic HTML structure.
- CSS Flexbox and Grid layouts.
- CSS positioning and alignment.
- Responsive web design using media queries.
- CSS transitions and hover effects.
- JavaScript DOM manipulation and event handling.
- Form design and styling.
- Organising and maintaining frontend code.

## Implementation Notes

The portfolio was developed to present my professional profile and web development projects in an organised and accessible format. HTML was used to structure the content, CSS to handle the visual design and responsive layouts and JavaScript to implement interactive functionality.

The website was deployed using Netlify and serves as a central showcase of my frontend development work and progress.
