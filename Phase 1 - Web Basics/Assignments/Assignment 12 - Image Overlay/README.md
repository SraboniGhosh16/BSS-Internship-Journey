# Assignment 12 - Image Overlay

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to create a hero section with a full-background image and a dark overlay to improve the visibility of the text and content displayed over the image.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 14
- **Assignment:** Image Overlay

## Live Demo

[**View the Project Website**](https://image-overlay-hyrwwt7w7-sraboni1.vercel.app)

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

## Features

- Full-screen hero section with a background image.
- Dark overlay using a CSS pseudo-element.
- Centered heading, paragraph and call-to-action button.
- Hover effect on the button.
- Responsive typography using a media query.

## Concepts Practised

- CSS positioning (`position: relative` and `position: absolute`).
- CSS pseudo-elements (`::before`).
- Background images and `background-size: cover`.
- Using RGBA colors to create a transparent overlay.
- Flexbox for content alignment.
- CSS media queries.
- Hover effects.

## Implementation Notes

The background image is applied to the hero section, while the `::before` pseudo-element creates a semi-transparent dark layer over it. The content is positioned above the overlay using the page layout. A media query adjusts the typography for smaller screens.
