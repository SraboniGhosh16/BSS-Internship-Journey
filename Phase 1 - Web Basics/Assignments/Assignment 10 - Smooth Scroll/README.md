# Assignment 10 - Smooth Scroll

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to create a single-page website with a sticky navigation header, multiple content sections and smooth scrolling between sections using HTML, CSS and JavaScript.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 10
- **Assignment:** Smooth Scroll Project

## Live Demo

[**View the Smooth Scroll Website**](https://smoothscrollpage.netlify.app/)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)

## Features

- Sticky navigation header.
- Navigation links for moving between page sections.
- Smooth scrolling between sections.
- Gradient backgrounds for the header and section headings.
- Header transparency effect when scrolling.
- Four project sections with images and descriptive text.
- Consistent typography and spacing throughout the page.

## Concepts Practised

- HTML section IDs and anchor links
- CSS smooth scrolling
- Flexbox navigation layout
- Sticky positioning using `position: sticky`
- CSS gradients and custom properties
- JavaScript DOM selection and event listeners
- Handling window scroll events
- Adding and removing CSS classes dynamically
- Navigation link styling and hover effects

## Implementation Notes

The project uses HTML to structure the navigation and content sections, CSS to style the layout and enable smooth scrolling and JavaScript to change the header's appearance based on the page's scroll position.

The project sections use placeholder text and images to demonstrate the layout and navigation behavior.
