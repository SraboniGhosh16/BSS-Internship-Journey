# Assignment 3 - CSS Basics Challenge (Sneaker Hut)

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to style a basic "Sneaker Hut" webpage using CSS properties and selectors provided in the course challenge.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 5
- **Assignment:** CSS Basics Challenge

## Live Demo

**[View the Sneaker Hut Website](https://sneakerhut.netlify.app)**

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Lato)

## Features

- A styled header with a contrasting background and centered heading.
- A navigation menu containing sneaker categories.
- Customized link colors and hover effects.
- A navigation menu with uppercase text and a light background.
- A highlighted introductory paragraph.

## Concepts Practised

- CSS selectors and class selectors
- Font families, sizes and weights
- Text alignment and text indentation
- Background and text colors
- Link states: `:hover` and `:active`
- List styling and padding
- Text transformation
- Google Fonts integration
