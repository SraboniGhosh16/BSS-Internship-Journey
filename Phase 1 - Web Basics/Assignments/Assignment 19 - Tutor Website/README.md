# Assignment 19 - Tutor Website

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to build a complete, responsive website for an online tutoring and video course platform. The project brings together the HTML, CSS, Flexbox, Grid, responsive design and JavaScript concepts covered in the course.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Modules:** Modules 17 and 18
- **Assignment:** Tutor Website

## Live Demo

[**View the Project Website**](https://tutor-bysraboni.vercel.app/)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Open Sans)
- Font Awesome

## Features

- Responsive landing page for an online tutoring platform.
- Separate Contact page with a contact form and office location map.
- Fixed navigation bar with a background effect on scrolling.
- Mobile navigation menu with a slide-in transition.
- Hero section with background imagery and call-to-action.
- Learning topics and course chapter sections.
- Course summary and key takeaways.
- Course details and author information sections.
- Statistics and newsletter subscription sections.
- Social media links and footer navigation.
- Responsive layouts for different screen sizes.

## Concepts Practised

- Semantic HTML5 structure.
- CSS custom properties (variables).
- CSS Flexbox and Grid layouts.
- CSS positioning (`relative`, `absolute` and `fixed`).
- CSS transitions and hover effects.
- Background images and overlays.
- CSS media queries and responsive design.
- Smooth scrolling.
- JavaScript DOM manipulation and event listeners.
- Mobile navigation using `classList.toggle()`.
- Scroll event handling using `window.scrollY`.
- Changing navigation bar styling dynamically based on scroll position.
- Working with external resources such as Google Fonts and Font Awesome.

## Implementation Notes

The website consists of a main landing page and a separate Contact page. Flexbox and Grid are used to organise the different content sections, while CSS media queries adapt the layouts for smaller screens. JavaScript controls the mobile navigation menu and dynamically changes the navigation bar's background styling when the user scrolls. CSS transitions are used to create smoother visual interactions throughout the website.
