# Assignment 8 - Flexbox Layout 2.0

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to update the original Flexbox Layout Challenge by applying the styling and responsive layout techniques covered in Module 8. The project focuses on improving the page layout and making its content adapt to different screen sizes.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 8
- **Assignment:** Responsive Flexbox Layout

## Live Demo

[**View the Responsive Flexbox Layout Website**](https://flexboxlayouts2.netlify.app/)

## Technologies Used

- HTML5
- CSS3

## Features

- Styled header and navigation bar.
- Main content and sidebar arranged using Flexbox.
- Improved spacing, alignment and position.
- Responsive layout for different screen sizes.
- Adaptable content arrangement on smaller screens.

## Concepts Practised

- CSS Flexbox
- `display: flex`
- Flex containers and flex items
- Flex sizing and alignment
- Margins and padding
- Typography and colors
- CSS media queries
- Responsive page layouts

## Implementation Notes

This project builds on the original Flexbox Layout Challenge by adding CSS styling and responsive behavior. Flexbox is used to organize the main content and sidebar, while responsive CSS rules help the layout adapt to different screen sizes.
