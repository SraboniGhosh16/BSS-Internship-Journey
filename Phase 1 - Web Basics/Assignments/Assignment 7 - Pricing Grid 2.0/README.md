# Assignment 7 - Pricing Grid 2.0

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to update the original HTML pricing grid by adding CSS styling and responsive behavior, following the instructions from Modules 7 and 8. The project focuses on improving the visual presentation and adapting the pricing layout to different screen sizes.
