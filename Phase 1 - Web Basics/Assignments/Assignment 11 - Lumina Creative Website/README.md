# Assignment 11 - Lumina Creative Website

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to build a multi-page creative agency website using HTML and CSS. The website includes a home page with a portfolio gallery; an about page showcasing services and team members; and a contact page with a contact form.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 11
- **Assignment:** Lumina Creative Website

## Live Demo

[**View the Lumina Creative Website**](https://luminacreativepages.netlify.app/)

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Open Sans)
- Font Awesome
- Lightbox2
- jQuery

## Features

- Three separate pages: Home, About and Contact.
- Navigation menu with active page highlighting.
- Hero sections with styled headings.
- Portfolio gallery featuring nine images.
- Lightbox effect for viewing portfolio images.
- Services section featuring Photography, Web Design and Graphic Design.
- Team section displaying three team members.
- Contact form with first name, last name, email and message fields.
- Footer with contact information and social media icons.
- Responsive layouts for different screen sizes.

## Concepts Practised

- Multi-page website structure and navigation
- Semantic HTML elements
- CSS Flexbox for layout and alignment
- CSS custom properties (variables)
- Reusable utility classes
- CSS selectors and pseudo-classes
- Responsive design using media queries
- Form elements and input styling
- Image galleries and hover effects
- External library integration using Lightbox2
- Google Fonts and Font Awesome integration

## Implementation Notes

The website is organized into three HTML pages that share a common stylesheet and consistent header and footer layouts. CSS Flexbox is used to arrange navigation menus, gallery items, service sections, team profiles and footer content.

CSS custom properties and reusable utility classes help maintain consistent styling throughout the website. A media query adjusts the layout for smaller screens.

Lightbox2 is integrated to display enlarged portfolio images when selected. The contact form is a front-end interface and is not connected to a backend service for processing submissions.
