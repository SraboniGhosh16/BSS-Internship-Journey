# Assignment 9 - Bono Landing Form

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to create a responsive landing page for a web application, featuring a contact form, background image, gradient overlay and styled header using HTML and CSS.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 9
- **Assignment:** Bono Landing Form

## Live Demo

[**View the Bono Landing Form Website**](https://bonolandingpage.netlify.app/)

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Open Sans)
- Font Awesome

## Features

- Header with logo, contact information and social media icon.
- Contact form with name, email and message fields.
- Background image with a gradient overlay.
- Styled form inputs and submit button.
- Flexbox layout for content alignment.
- Responsive design using CSS media queries.
- Hover effects on links and the submit button.

## Concepts Practised

- HTML document structure and forms
- Form labels, inputs and textareas
- CSS Flexbox and alignment
- Background images and linear gradients
- Margins, padding and spacing
- Form styling and button hover effects
- Google Fonts and Font Awesome integration
- Responsive design using media queries

## Implementation Notes

The project uses HTML for the page structure and CSS for layout, styling, background effects and responsiveness. The background image and logo are loaded from the project's local images directory.

The contact form is a front-end interface and is not connected to a backend service for processing submissions.
