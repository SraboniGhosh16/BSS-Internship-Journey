# Assignment 14 - Grid Challenge 1

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to practise CSS Grid by arranging twelve items in a structured grid layout with different row sizes and automatically generated rows.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 15
- **Assignment:** Grid Challenge 1

## Live Demo

[**View the Project Website**](https://grid-challenge-1-j3tuzqlpc-sraboni1.vercel.app)

## Technologies Used

- HTML5
- CSS3

## Features

- Grid layout containing twelve items.
- Three equally sized columns.
- Rows with different proportions.
- Automatically generated rows for additional grid items.
- Consistent spacing between grid items.

## Concepts Practised

- CSS Grid layout (`display: grid`).
- `grid-template-columns`.
- `grid-template-rows`.
- The `repeat()` function.
- Fractional units (`fr`).
- `grid-auto-rows`.
- Grid gaps.

## Implementation Notes

The layout uses three columns created with `repeat(3, 1fr)`. The first three rows have different fractional proportions, while `grid-auto-rows` defines the sizing of additional automatically generated rows. This exercise helped me understand explicit and implicit grid tracks.
