# Assignment 13 - Smooth Scroll 2.0, Selectors Challenge

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to update the Smooth Scroll project by applying different CSS selectors and creating a sticky navigation bar with a transparent background effect.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 14
- **Assignment:** Smooth Scroll 2.0, Selectors Challenge

## Live Demo

[**View the Project Website**](https://smoothscroll20-ci9r2vv2c-sraboni1.vercel.app)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)

## Features

- Sticky navigation bar.
- Smooth scrolling between page sections.
- Transparent navigation bar styling.
- Multiple content sections with images and lists.
- Different background styles applied using CSS selectors.

## Concepts Practised

- CSS smooth scrolling (`scroll-behavior`).
- CSS sticky positioning.
- CSS custom properties (variables).
- CSS pseudo-classes and advanced selectors.
- Structural selectors such as `:first-of-type`, `:nth-child()` and `:nth-of-type()`.
- The `:has()` pseudo-class.
- Attribute selectors.
- Adjacent sibling selector (`+`).
- JavaScript event handling and DOM manipulation.

## Implementation Notes

The project uses CSS selectors to target specific elements based on their position, attributes and relationships with other elements. CSS custom properties are used to control the transparency of the navigation background. JavaScript is included for the navigation bar's interactive behavior.
