# Assignment 20 - Leno App: Health & Productivity

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to build a responsive multi-page website for Leno, a health and productivity application. The project focuses on creating a modern landing page with testimonials, feature highlights, video previews, screenshots, download options and a separate details page with pricing information.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Modules:** Modules 19 and 20
- **Assignment:** Leno App - Health & Productivity

## Features

- Responsive landing page for a health and productivity application.
- Separate Details page with pricing plans and feature information.
- Fixed navigation bar with dynamic background styling on scroll.
- Mobile navigation menu with a slide-in transition.
- Hero section with application introduction and download links.
- Customer testimonials section.
- Application features presented using a structured grid layout.
- Video preview with a modal popup.
- Key takeaways and application details sections.
- Application screenshots gallery.
- Download section with call-to-action buttons.
- Footer with quick links and social media links.
- Responsive layouts for different screen sizes.

## Implementation Notes

The project consists of two HTML pages: the main landing page (`index.html`) and a separate details page (`details.html`). CSS Flexbox and Grid are used to organise the different sections, while media queries provide responsive layouts. JavaScript handles the mobile navigation menu, dynamically changes the navbar styling when scrolling and controls the video modal. The video is loaded into an embedded player when the preview button is clicked and its source is cleared when the modal is closed.
