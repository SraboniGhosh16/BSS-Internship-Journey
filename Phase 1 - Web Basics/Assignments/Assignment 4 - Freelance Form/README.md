# Assignment 4 - Freelance Form

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to build a freelancer project submission card and practise CSS layout, spacing and styling using the box model.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 6
- **Assignment:** Freelance Form Project

## Live Demo

**[View the Freelance Form](https://freelancerform.netlify.app)**

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

## Features

- A centered card with a dark background.
- A heading and short introductory description.
- A text input for describing a project.
- A "Post a Project" button.
- Rounded corners and a box shadow.
- A gradient background and hover effect on the button.

## Concepts Practised

- CSS box model
- Width, margin and padding
- Horizontal centering with `margin: auto`
- Background and text colors
- Border radius and box shadow
- Styling form inputs and buttons
- CSS gradients
- Hover states
- Google Fonts integration

## Implementation Notes

The page was created with HTML and an external CSS stylesheet. It is a front-end practice project; the form does not submit project information to a backend.
