# Assignment 16 - Lumina Creative Website 2.0

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to update the Lumina Creative website by replacing the previous gallery layout with CSS Grid and applying grid-based positioning to create a more structured and responsive image gallery.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 15
- **Assignment:** Lumina Creative Website 2.0

## Live Demo

[**View the Project Website**](https://luminacreative20-2xlck7ll2-sraboni1.vercel.app)

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Open Sans)
- Font Awesome

## Features

- Multi-page creative agency website.
- Home, About and Contact pages.
- Image gallery arranged using CSS Grid.
- Gallery items with different column and row spans.
- Services and team sections.
- Contact form.
- Responsive layouts for smaller screens.

## Concepts Practised

- CSS Grid layout (`display: grid`).
- `grid-template-columns`.
- `grid-column` and `grid-row`.
- Spanning grid items across multiple columns and rows.
- Using `nth-of-type()` to target specific gallery items.
- Responsive Grid layouts with media queries.
- Combining CSS Grid and Flexbox.
- CSS custom properties and reusable utility classes.

## Implementation Notes

The gallery now uses CSS Grid with three columns on larger screens. Selected gallery items span multiple columns or rows to create a varied layout. Media queries adjust the gallery structure and other page sections for smaller screens. Flexbox is retained for layouts such as the header, services, team and footer sections.
