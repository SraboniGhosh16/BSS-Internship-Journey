# Assignment 15 - Grid Challenge 2

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to build a page layout using CSS Grid, arranging common website sections such as the header, navigation, search area, main content, sidebar and footer.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 15
- **Assignment:** Grid Challenge 2

## Live Demo

[**View the Project Website**](https://grid-challenge-2-kjv767ic5-sraboni1.vercel.app)

## Technologies Used

- HTML5
- CSS3

## Features

- Full-page grid layout.
- Header and footer spanning across both columns.
- Main content and sidebar arranged in separate columns.
- Navigation and search sections.
- Responsive single-column layout for smaller screens.

## Concepts Practised

- CSS Grid layout (`display: grid`).
- Defining columns using fractional units.
- Defining rows using `grid-template-rows`.
- Grid item positioning with `grid-column`.
- Using `span` to make elements occupy multiple columns.
- CSS media queries.
- Responsive grid layouts.

## Implementation Notes

The main container uses a two-column grid with a wider content area and a narrower sidebar. The header and footer span both columns. A media query changes the layout to a single column on screens narrower than 768px.
