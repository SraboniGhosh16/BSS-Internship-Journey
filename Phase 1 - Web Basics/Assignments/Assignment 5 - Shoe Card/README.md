# Assignment 5 - Shoe Cards

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to create three shoe collection cards using HTML and CSS, practising reusable styles, background images, spacing and visual presentation.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 6
- **Assignment:** Shoe Cards Project

## Live Demo

**[View the Shoe Cards Website](https://shoescards.netlify.app)**

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Lato)

## Features

- Three shoe collection cards: Sporty, Casual and Formal.
- A different shoe image for each card.
- Individual heading and button colors for each collection.
- Rounded card corners and box shadows.
- Hover effects on collection links.
- A consistent layout for all three cards.

## Concepts Practised

- Reusable CSS classes
- Multiple classes on a single HTML element
- CSS background images
- Background positioning and sizing
- Margins and padding
- Border radius and box shadow
- Link styling and hover effects
- Organizing repeated components with HTML

## Implementation Notes

The project uses shared CSS rules for the common card layout and additional classes for collection-specific styles. The shoe images are loaded from the project's local `images` directory.

The "View Collection" links are visual placeholders and do not navigate to actual product collections.
