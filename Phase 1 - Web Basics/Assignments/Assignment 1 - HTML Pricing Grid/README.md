# Assignment 1 - HTML Pricing Grid

## Overview

This assignment is part of my HTML learning journey during the BSS Software Engineering Internship. The goal was to recreate a pricing section containing three subscription plans using HTML only, following the Udemy course example.

## Live Demo

**[View the HTML Pricing Grid](https://htmlpricinggrid.netlify.app)**

## Technologies Used

- HTML5

## Features

The page presents three pricing plans:

- **Free:** A starter plan with basic features.
- **Pro:** A plan for users working on larger projects.
- **Enterprise:** A plan with unlimited features.

Each plan includes its price, a short description, a "Get Started" link and a list of features.

## HTML Concepts Practised

- HTML document structure and metadata
- `<div>` for grouping content
- Headings and paragraphs
- `<sup>` and `<span>` for inline content
- `<strong>` for emphasized text
- Anchor tags (`<a>`) for links
- Unordered lists (`<ul>` and `<li>`)
- HTML class attributes

## Implementation Notes

The assignment was implemented using HTML without custom CSS or JavaScript. The page therefore uses the browser's default styling.

The class attributes are included to reflect the structure of the course example, although they do not apply custom styling without corresponding CSS.

## What I Learned

- How to organize related content using HTML elements.
- How to structure repeated pricing plans consistently.
- How to use lists and links to present plan information.
- How semantic and structural HTML elements contribute to a webpage.
