# Assignment 2 - HTML Apartment Search Form

## Overview

This assignment is part of my HTML learning journey during the BSS Software Engineering Internship. The objective was to build a simple apartment search form using HTML form elements, following the Udemy course example.

## Live Demo

**[View the HTML Apartment Search Form](https://htmlapartmentform.netlify.app)**

## Technologies Used

- HTML5

## Form Fields

The form includes the following fields:

- **Location:** Text input for a location.
- **Price:** Range slider for selecting a price value.
- **Bedrooms:** Number input for the number of bedrooms.
- **Bathrooms:** Number input for the number of bathrooms.
- **Pets:** Checkbox indicating whether pets are allowed.
- **Date Available:** Date picker for the availability date.
- **Submit:** Button to submit the form.

## HTML Concepts Practised

- HTML document structure
- Forms and the `<form>` element
- Labels and input fields
- Input types: `text`, `range`, `number`, `checkbox`, `date` and `submit`
- Connecting labels to inputs using `for` and `id`
- Form attributes such as `type`, `name` and `value`
- Organizing form fields using `<div>`
- Using `<br>` for line breaks

## Implementation Notes

The form was created using HTML only, without custom CSS or JavaScript. The browser's default styling is used.

This is a practice form. It does not connect to an apartment database or implement actual search functionality.

## What I Learned

- How to create forms using different HTML input types.
- Why labels should be associated with their respective inputs.
- How input attributes control the type and range of accepted values.
- How to group form fields into a structured layout.
