# Assignment 18 - Presentation Website

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to create a multi-section presentation website with full-screen page sections, smooth navigation, CSS transitions and animated content.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 16
- **Assignment:** Presentation Website

## Live Demo

[**View the Project Website**](https://my-presentation-website.vercel.app/)

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome

## Features

- Four full-screen presentation sections.
- Different background colours for each section.
- Previous and Next navigation buttons.
- Smooth scrolling between sections.
- Animated heading and paragraph on the first page.
- Hover transitions on navigation buttons.
- Responsive typography for smaller screens.

## Concepts Practised

- CSS Flexbox.
- CSS custom properties (variables).
- CSS smooth scrolling (`scroll-behavior`).
- CSS transitions.
- CSS animations using `@keyframes`.
- CSS transforms (`translateX()` and `translateY()`).
- Animation timing and duration.
- CSS media queries.
- CSS nested selectors.

## Implementation Notes

The website is divided into four full-screen sections, each identified by a unique ID. Previous and Next buttons use anchor links to navigate between sections. CSS custom properties control the section colours and animation speed. The first section uses keyframe animations to bring the heading and paragraph into view, while transitions provide hover effects on the navigation buttons.
