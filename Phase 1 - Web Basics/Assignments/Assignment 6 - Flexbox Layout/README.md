# Assignment 6 - Flexbox Layout Challenge

## Overview

This assignment is part of my learning journey through *Modern HTML & CSS From The Beginning 2.0* during the BSS Software Engineering Internship.

The objective was to create a webpage layout using CSS Flexbox, including a full-width header, a horizontal navigation menu and a main content area with an article and sidebar.

## Course Information

- **Course:** Modern HTML & CSS From The Beginning 2.0
- **Module:** Module 7
- **Assignment:** Flexbox Layout Challenge

## Live Demo

**[View the Flexbox Layout](https://flexboxlayouts.netlify.app)**

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

## Features

- A full-width header with a contrasting background.
- A horizontal navigation menu.
- An article section containing headings and paragraphs.
- A sidebar displaying a list of recent posts.
- A two-column layout built with Flexbox.
- Responsive behavior for smaller screens.

## Concepts Practised

- CSS Flexbox
- `display: flex`
- `flex` for distributing available space
- `gap` for spacing between elements
- Navigation menu layout
- Main content and sidebar alignment
- CSS reset and `box-sizing`
- Responsive layouts using media queries
- Semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>` and `<aside>`

## Implementation Notes

The page uses Flexbox to align navigation items horizontally and position the main article and sidebar side by side. A media query changes the main layout to a vertical arrangement on narrower screens.
