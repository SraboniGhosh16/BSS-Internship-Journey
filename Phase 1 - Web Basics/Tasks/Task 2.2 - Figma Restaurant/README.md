# Task 2.2 - Figma Restaurant Website

## Overview

This task was assigned as part of my BSS Software Engineering Internship.

The objective was to convert a restaurant website design from Figma into a responsive, full-page website using HTML, CSS and JavaScript. The implementation focuses on recreating the design, building standard website sections, adding interactive elements and ensuring a responsive layout across different screen sizes.

## Task Information

- **Program:** BSS Software Engineering Internship
- **Task:** Task 2.2 - Figma Restaurant Website
- **Design Reference:** Figma - Restaurant Website

- HTML5

- Font Awesome
- Google Fonts
- Formspree (Contact Form Integration)

## Features

- Responsive navigation bar with a mobile menu.
- Hero section featuring background imagery, promotional content and a call-to-action.
- About section with an image, interactive tabs and service highlights.
- Popular food items section with navigation buttons to rearrange the displayed items.
- Table reservation section with a contact form.
- Customer testimonial section with review content and food imagery.
- Footer featuring restaurant information and social media links.
- Responsive layouts for desktop, tablet and mobile screens.
- Navigation bar background changes when scrolling.

## Concepts Practised

- Semantic HTML structure and page section organization.
- CSS Flexbox and Grid layouts.
- Responsive web design using media queries.
- CSS positioning, background images and overlays.
- CSS transitions and hover effects.
- JavaScript DOM manipulation and event listeners.
- Interactive tab functionality using `data-*` attributes and element IDs.
- Mobile navigation toggle functionality.
- Dynamically rearranging elements using JavaScript.
- HTML form structure and external form integration.

## Implementation Notes

The website was developed by translating the Figma restaurant design into a complete multi-section webpage. Flexbox, Grid and media queries were used to build the layouts and adapt them to smaller screens. JavaScript was implemented for the mobile navigation menu, interactive About tabs, menu item rearrangement and scroll-based navbar styling. The reservation form is connected to Formspree for form submission.
