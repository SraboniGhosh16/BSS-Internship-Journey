# Task 2.1 - Figma Conversion: Convention Center

## Overview

This task was assigned as part of my BSS Software Engineering Internship.

The objective was to convert a Figma design into a fully responsive Convention Center landing page using HTML, CSS and JavaScript. The task focused on recreating the design, implementing standard website sections and building interactive navigation and UI components.

## Features

- Responsive navigation bar with desktop menu and mobile hamburger menu.
- Hero section featuring an automatic image slider with manual previous/next navigation and slide indicators.
- Explore Album section with responsive layout.
- Dismissible promotional notification.
- Pricing section with four package cards and hover effects.
- Happy Clients section featuring testimonial cards.
- Interactive FAQ section with expandable and collapsible answers.
- Responsive footer with App Store and Google Play badges.
- Responsive layouts for desktop and mobile screens.

## Concepts Practised

- Semantic HTML structure and reusable CSS classes.
- CSS Flexbox and Grid for page layouts.
- CSS positioning, transitions, transforms and hover effects.
- Responsive web design using media queries.
- JavaScript DOM manipulation and event listeners.
- Image slider functionality using JavaScript.
- Updating active slide indicators.
- Toggling mobile navigation and FAQ answers.
- Implementing dismissible UI elements.

## Implementation Notes

The website was developed by translating the provided Figma design into a responsive webpage. The hero slider uses JavaScript to handle automatic transitions and manual navigation through previous and next buttons. CSS transitions and transforms were used to create smooth visual effects, while media queries were applied to adapt the layout to smaller screens. JavaScript event listeners were also used to implement the mobile navigation menu, promotional notification dismissal and interactive FAQ section.
