# Project 5 - Vera Website

## Overview

This project is part of Phase 2 of my learning journey through the BSS Software Engineering Internship.

The objective was to develop a responsive business website for *Vera*, a company offering software solutions for small businesses, startups and enterprises. The website presents the company's software solutions, expertise, pricing plans, completed projects and business services through a modern dark-themed design.

## Features

- Responsive navigation bar with scroll-based styling.
- Dark-themed hero section with animated rotating text.
- Partners section displaying company logos.
- Information request form.
- Software solutions section covering ERP, CRM, SFA and WMS.
- Company details and expertise sections.
- Video section with a Bootstrap modal.
- Animated video play button.
- Pricing section featuring Standard, Advanced and Complete plans.
- Project gallery displaying six projects.
- Individual Bootstrap modals for project details.
- Newsletter subscription section.
- Footer with company information and navigation links.
- Responsive layout for different screen sizes.

- Bootstrap navigation and utility classes.
- Bootstrap cards and pricing layouts.
- Bootstrap modal components and JavaScript events.
- Bootstrap forms and input groups.
- JavaScript DOM manipulation and event handling.
- Implementing scroll-based navbar effects.
- Integrating ReplaceMe.js for animated text transitions.
- Controlling video playback through modal events.
- Sass variables, nesting and custom styling.
- CSS positioning, transitions and responsive media queries.

## Implementation Notes

The website is divided into sections covering partners, information requests, software solutions, company expertise, pricing, projects and newsletter subscriptions. ReplaceMe.js is used to create rotating text in the hero section. Bootstrap modals are used to display video content and additional information about individual projects. JavaScript handles navbar styling during scrolling and controls video playback when the modal is opened or closed. Sass and Bootstrap utilities are used to create the responsive dark-themed interface.
