# Project 3 - Portfolio Website

## Overview

This project is part of Phase 2 of my learning journey through the BSS Software Engineering Internship.

The objective was to create a responsive personal portfolio website for a web developer. The website introduces the developer, presents personal information and technical skills, showcases projects, highlights services and provides a contact section.

## Course Information

- **Program:** BSS Software Engineering Internship
- **Phase:** Phase 2
- **Project:** Project 3 - Portfolio Website

## Live Demo

[**View the Project Website**](https://portfolio-website-project3.netlify.app/)

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Sass (SCSS)
- JavaScript
- Font Awesome
- Lightbox

## Features

- Responsive navigation and full-height hero section.
- Typewriter text animation in the hero section.
- About Me section with personal information.
- Profile and technical skills section.
- Portfolio gallery displaying six projects.
- Lightbox popups for viewing project images.
- Services section covering web design, web development and advertising and SEO.
- Statistics section displaying clients, projects and other achievements.
- Contact section with a message form.
- Dark and light visual contrast throughout the design.
- Responsive layout for different screen sizes.

## Concepts Practised

- Bootstrap grid system and responsive containers.
- Bootstrap navigation and utility classes.
- Bootstrap progress bars and layout components.
- Bootstrap responsive image and typography utilities.
- JavaScript DOM manipulation and event handling.
- JavaScript `setTimeout()` for typewriter animation.
- Integrating the Lightbox library for image previews.
- Sass variables, nesting and custom styling.
- CSS background images, overlays and transitions.
- Responsive design using CSS media queries.

## Implementation Notes

The portfolio is organised into About, Profile, Skills, Portfolio, Services, Statistics and Contact sections. JavaScript creates a typewriter effect in the hero section by displaying the introductory text character by character. The Lightbox library provides an interactive way to preview project images, while Bootstrap components and custom Sass styling are used to build the responsive layout.
