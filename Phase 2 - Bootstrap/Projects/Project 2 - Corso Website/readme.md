# Project 2 - Corso Website

## Overview

This project is part of Phase 2 of my learning journey through the BSS Software Engineering Internship.

The objective was to develop a responsive website for a training and seminar platform. The website presents training videos, learning opportunities, course information, key takeaways and upcoming events through a modern layout combining light and dark sections.

## Technologies Used

## Features

- Responsive navigation bar with scroll-based background styling.
- Hero section with training and seminar video content.
- Image carousel showcasing training videos.
- Registration section with an input form.
- Course details and learning benefits.
- Six key learning points.
- Course summary section.
- Event invitation section highlighting an upcoming seminar.
- Key takeaways presented in a structured card layout.
- Email subscription form.
- Footer with navigation and social links.
- Responsive layout for different screen sizes.

## Concepts Practised

- Bootstrap grid system and responsive breakpoints.
- Bootstrap navigation and responsive navbar.
- Bootstrap carousel component.
- Bootstrap forms and input groups.
- Bootstrap cards and layout utilities.
- Bootstrap Flexbox and spacing utilities.
- Sass variables, nesting and custom styling.
- JavaScript DOM selection and scroll event handling.
- CSS media queries and responsive adjustments.

## Implementation Notes

The website is divided into sections covering training content, registration, course details, learning points, course summaries, seminar invitations and key takeaways. The image carousel presents different training and seminar videos, while the registration and subscription sections provide user input forms. JavaScript is used to change the navbar background when the user scrolls down the page. Sass is used to organise and customise the website's styling.
