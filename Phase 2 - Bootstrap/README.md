# Phase 2 - Web Basics (Bootstrap 5)

## Overview

This phase focuses on learning Bootstrap 5 and using its components, grid system and utility classes to build responsive and visually appealing web layouts. It covers creating reusable UI components, customising Bootstrap styles and converting Figma designs into responsive web pages.

## Learning Topics

- Bootstrap 5 grid system and breakpoints
- Navbar, cards and modals
- Responsive layouts using Bootstrap
- Customising and overriding Bootstrap styles
- Bootstrap utility classes for spacing, Flexbox and display
- Forms and validation with Bootstrap
- Modal customisation and dynamic content
- Offcanvas components and side navigation menus
- Carousel controls and autoplay settings
- Accordions, toasts and alerts
- Bootstrap Icons and SVG integration
- Icon alignment with text
