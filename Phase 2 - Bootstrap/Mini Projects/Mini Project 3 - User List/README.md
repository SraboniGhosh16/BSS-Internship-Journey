# Mini-Project 3 - User List

## Overview

This mini-project is part of my learning journey through *Bootstrap 5 from Scratch* during the BSS Software Engineering Internship.

The objective was to create a user listing interface that displays user profiles in an organised card-based layout. The project focuses on using Bootstrap's grid system, cards, navigation components, badges and popovers to build a responsive user directory.

## Course Information

## Features

- User directory displaying six user profiles.
- Profile cards containing user images, names and locations.
- Interest and category badges for each user.
- Email information displayed through Bootstrap popovers.
- User search input field.
- Navigation links for Reputation, New Users, Editors and Moderators.
- Dark and light theme toggle buttons.
- Responsive three-column user card layout.
- Mobile navigation alignment adjustments.

## Concepts Practised

- Bootstrap card components.
- Bootstrap badges and navigation components.
- Bootstrap utility classes for Flexbox, spacing and alignment.
- Bootstrap responsive image and rounded-circle utilities.
- Bootstrap popovers and their JavaScript initialisation.
- Bootstrap colour modes and theme customisation.
- JavaScript DOM selection and event handling.
- CSS media queries for responsive adjustments.
- Working with external image resources.

## Implementation Notes

The user directory displays six profile cards arranged using Bootstrap's grid system. Each card contains a profile image, user name, location and interest badges. Bootstrap popovers are initialised using JavaScript to display the email address associated with each profile when the card is interacted with. Dark and light theme options are provided through theme toggle buttons, while Bootstrap utility classes and a custom media query are used to adjust the layout and alignment across different screen sizes.
