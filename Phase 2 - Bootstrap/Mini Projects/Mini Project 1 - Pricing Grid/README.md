# Mini-Project 1 - Pricing Card

## Overview

This mini-project is part of my learning journey through *Bootstrap 5 from Scratch* during the BSS Software Engineering Internship.

The objective was to create a pricing section featuring two subscription plans using Bootstrap components and utility classes. The project focuses on building structured pricing cards with a responsive layout using Bootstrap's grid system.

## Course Information

- **Course:** Bootstrap 5 from Scratch
- **Module:** Module 5
- **Project:** Mini-Project 1 - Pricing Card

## Features

- Two subscription pricing plans: Free and Pro.
- Bootstrap card components with customised styling.
- Feature lists for each subscription plan.
- Different visual styles for the two pricing cards.
- Subscription buttons with Bootstrap styling.
- Responsive two-column layout using the Bootstrap grid system.
- Bootstrap utility classes for spacing, typography, colours and alignment.

## Concepts Practised

- Bootstrap grid system (`container`, `row` and `col-md-6`).
- Bootstrap card components.
- Bootstrap buttons and list groups.
- Bootstrap utility classes for spacing and typography.
- Bootstrap background and text colour utilities.
- Bootstrap Icons integration.
- Customising Bootstrap components using utility classes.
- Responsive layouts using Bootstrap breakpoints.

## Implementation Notes

The pricing section consists of two cards representing Free and Pro subscription plans. Bootstrap's grid system is used to arrange the cards side by side on medium and larger screens, while the layout stacks them on smaller screens. Bootstrap card, list group and button components are used to structure the content, with utility classes applied to customise spacing, typography, colours, borders and shadows. Bootstrap Icons are used to display check marks alongside the plan features.
