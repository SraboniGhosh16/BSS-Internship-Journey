# Mini-Project 2 - Ratings Component

## Overview

This mini-project is part of my learning journey through *Bootstrap 5 from Scratch* during the BSS Software Engineering Internship.

The objective was to build a product ratings component that presents an average rating, a review search field and a breakdown of reviews by star rating. The project focuses on using Bootstrap components and utility classes to create a clean and organised interface.

## Course Information

- **Course:** Bootstrap 5 from Scratch
- **Module:** Module 5
- **Project:** Mini-Project 2 - Ratings Component

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome

## Features

- Product rating summary displaying an average rating of 4.8.
- Star icon alongside the average rating.
- Search Reviews input field.
- Review breakdown organised by star ratings from 1 to 5.
- Visual rating distribution using Bootstrap progress component markup.
- Write Review button.
- Rounded input group and card-based layout.
- Bootstrap utility classes for spacing, typography, colours and alignment.

## Concepts Practised

- Bootstrap containers, rows and columns.
- Bootstrap card components.
- Bootstrap input groups and form controls.
- Bootstrap progress component.
- Bootstrap buttons and utility classes.
- Bootstrap spacing and typography utilities.
- Font Awesome icon integration.
- Customising Bootstrap components using CSS.
- Responsive layout considerations.

## Implementation Notes

The component is organised into separate sections for the average rating, review search field, star-rating breakdown and Write Review button. Bootstrap's card and grid components provide the overall structure, while input groups and progress component markup are used for the search field and rating distribution. Font Awesome provides the search and star icons, and Bootstrap utility classes are used to style and align the different elements.
