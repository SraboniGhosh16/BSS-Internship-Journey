# Task - Figma eCommerce Website

## Overview

This task was assigned as part of my BSS Software Engineering Internship, Phase 2.

The objective was to convert an eCommerce website design from Figma into a responsive, multi-page website using HTML, CSS, Bootstrap and JavaScript. The implementation focuses on recreating the SHOP.CO design, building an online shopping interface, organising product listings and filter sections, adding interactive elements and ensuring responsiveness across different screen sizes.

## Implementation Notes

The website was developed by translating the SHOP.CO Figma design into a responsive, multi-page eCommerce interface. The homepage includes promotional sections, brand showcases, product collections, dress style categories, customer reviews and a newsletter area. A separate category page displays product listings alongside a filter sidebar containing category, price, colour, size and dress style options.

Bootstrap 5 was used extensively for the grid system, responsive layouts, navigation, dropdowns, cards, buttons and Offcanvas components. Sass was used to customise Bootstrap styles and implement additional design adjustments.

JavaScript was implemented to change the navigation bar's appearance when scrolling and dynamically rearrange customer review cards using navigation buttons. The filter sidebar uses a responsive Offcanvas layout, appearing as a regular sidebar on larger screens and sliding up from the bottom on smaller screens.
